### Machine Learning & Deep Learning

#### [Maize Yield Anomaly Detection](https://github.com/Deirdre24/Data-Analysis-Portfolio.git)
**Tools:** Python, CNN, LSTM, scikit-learn
**Type:** Individual Academic Project | 2025

Developed a deep learning framework to detect pre-harvest maize yield anomalies across Southern Africa using satellite-derived NDVI and rainfall time-series data. Built and evaluated CNN and LSTM models against a Random Forest baseline, achieving **0.906 AUC and a 51.9% improvement** over the non-sequential approach.

#### [Hotel Customer Segmentation & Predictive Analytics](https://github.com/Deirdre24/Customer-Segmentation-using-Supervised-and-Unsupervised-Learning-Methods.git)
**Tools:** R, K-Means, DBSCAN, Random Forest, Neural Networks
**Type:** Academic Group Project — Team Leader | 2024

Led a team project to segment hotel customers using supervised and unsupervised machine learning techniques. Applied K-Means, DBSCAN, Logistic Regression, Random Forest, and Neural Networks across the full ML lifecycle in R.

#### [Intelligent Systems — Decision Trees & Neural Networks](https://github.com/Deirdre24/Intelligent-Systems-Project.git)
**Tools:** Python, Keras, scikit-learn
**Type:** Individual Academic Project | 2024

Built a neural network to classify productivity levels using lifestyle features, applying dropout, class weighting, and early stopping. Developed an interpretable ID3 decision tree and applied forward/backward chaining for inference and hypothesis validation.
